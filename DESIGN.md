# DreamGuard Design System & Product Specification

## 1. Product Overview
DreamGuard is an autonomous cross-margin risk sentinel and funding rate yield harvester built for dreamDEX perpetual futures on Somnia Tokyo Testnet.

## 2. Visual Direction & Color Palette
- Ground / Background: `#07090e` (Deep Void Obsidian)
- Card / Panel Surface: `#0f141f` (Tactical Slate)
- Border / Grid Lines: `#1e293b`
- Primary Accent: `#8b5cf6` (Somnia Reactive Violet)
- Bull / Yield Accent: `#10b981` (Emerald Green)
- Bear / Short Accent: `#f43f5e` (Rose Crimson)
- Caution / Health Trim: `#f59e0b` (Amber)
- Danger / Liquidation: `#ef4444` (Vivid Red)
- Typography: Inter, SF Pro, JetBrains Mono for on-chain telemetry and hashes

## 3. Core Principles
- Studio-grade dark tactical aesthetic.
- Zero generic boilerplate or placeholder text.
- Monospace styling for all addresses, hashes, rates, and balances.
- Real-time on-chain verification backed by Somnia Hideki JSON-RPC.
- Zero em-dash typography standard.
